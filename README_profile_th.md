# สวัสดีค่ะ 👋 ยินดีต้อนรับสู่พื้นที่รวบรวมผลงานของฉัน

พื้นที่นี้รวบรวมโปรเจกต์ด้าน **Data Analytics, Python และ SQL** ที่ฉันพัฒนาขึ้นระหว่างเรียนปริญญาโท โดยมีเป้าหมายเพื่อฝึกนำความรู้จากห้องเรียนมาประยุกต์ใช้กับข้อมูลจริงในรูปแบบของโปรเจกต์ที่สามารถอธิบายขั้นตอนการทำงานและเหตุผลในการตัดสินใจได้

## เกี่ยวกับฉัน

ฉันจบการศึกษาระดับปริญญาตรีจาก **คณะวิศวกรรมศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย สาขาวิศวกรรมสำรวจ** และกำลังศึกษาต่อในระดับปริญญาโทด้าน **Data Science and Statistics / Data Science** ที่จุฬาลงกรณ์มหาวิทยาลัย

แม้เส้นทางการเรียนในระดับปริญญาตรีจะไม่ได้ตรงกับสาย Data Analytics โดยตรง แต่ฉันตั้งใจเรียนรู้และพัฒนาทักษะที่จำเป็นเพิ่มเติม ทั้งการเขียนโค้ด การจัดการข้อมูล การวิเคราะห์เชิงสถิติ และการสื่อสารผลลัพธ์ทางธุรกิจ ฉันเชื่อว่าการเรียนรู้ไม่ได้จบลงแค่ในห้องเรียน จึงเริ่มสร้างโปรเจกต์ของตัวเองเพื่อฝึกลงมือทำ แก้ปัญหา และพัฒนาผลงานที่สะท้อนการเรียนรู้ทีละขั้น

เป้าหมายของฉันคือการนำข้อมูลมาเปลี่ยนเป็นข้อค้นพบที่เข้าใจง่าย มีเหตุผลรองรับ และสามารถนำไปใช้ประกอบการตัดสินใจได้

## ทักษะที่กำลังพัฒนา

- **Python:** ใช้ `pandas` สำหรับสำรวจและจัดการข้อมูล และใช้ไลบรารีสร้างกราฟเพื่อสื่อสารผลการวิเคราะห์
- **SQL:** ใช้คำสั่ง `SELECT`, `WHERE`, `GROUP BY`, aggregate functions และการคำนวณอัตราส่วนเพื่อเปรียบเทียบกลุ่มข้อมูล
- **Exploratory Data Analysis (EDA):** ตรวจสอบโครงสร้างข้อมูล ค่าว่าง ข้อมูลซ้ำ และการกระจายของตัวแปร
- **Data Visualization:** เลือกกราฟให้เหมาะกับคำถามและอธิบายสิ่งที่กราฟแสดง
- **Business Thinking:** เชื่อมโยงผลวิเคราะห์กับคำถามทางธุรกิจ พร้อมระบุข้อจำกัดของข้อมูล

> ทักษะเหล่านี้เป็นทักษะที่กำลังฝึกฝนผ่านการเรียนและโปรเจกต์ โดยจะปรับปรุงรายการให้สอดคล้องกับประสบการณ์จริงอย่างต่อเนื่อง

## ผลงานและโปรเจกต์

### 1. Bank Marketing Analysis — Python + SQL
**สถานะ:** กำลังพัฒนา

วิเคราะห์ข้อมูลการสมัครเงินฝากประจำ เพื่อฝึกตรวจสอบคุณภาพข้อมูล สำรวจอัตราการสมัครในแต่ละกลุ่ม และใช้ SQL เปรียบเทียบปัจจัยต่าง ๆ เช่น ระดับการศึกษา เดือนที่ติดต่อ และจำนวนครั้งที่ติดต่อ

สิ่งที่ฝึกจากโปรเจกต์นี้:
- ตรวจสอบค่าว่าง ข้อมูลซ้ำ และค่าหมวดหมู่ เช่น `unknown`
- ใช้ Python ทำ EDA และสร้างกราฟ
- ใช้ SQL สรุปจำนวนลูกค้าและอัตราการสมัครในแต่ละกลุ่ม
- แปลงผลวิเคราะห์เป็นข้อเสนอแนะ โดยไม่สรุปความเป็นเหตุเป็นผลเกินกว่าที่ข้อมูลรองรับ

ชุดข้อมูล: [Kaggle Playground Series S5E8 — Binary Classification with a Bank Dataset](https://www.kaggle.com/competitions/playground-series-s5e8/data)

**ข้อจำกัด:** ชุดข้อมูลนี้เป็นข้อมูลสังเคราะห์ที่อ้างอิงจาก Bank Marketing dataset ต้นฉบับ จึงไม่ควรอธิบายว่าเป็นข้อมูลแคมเปญจริงในปี 2025
